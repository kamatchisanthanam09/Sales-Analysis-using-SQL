# Sales-Analysis-using-SQL
Sales Data Analysis Using Oracle

====================================================
           SALES ANALYSIS USING SQL
====================================================

DATABASE : Oracle SQL
TOOL     : Oracle SQL*Plus
PROJECT  : Sales Data Analysis

PROJECT DESCRIPTION:
This project analyzes sales transactions,
customer purchases, product performance,
revenue, and profitability using Oracle SQL.

The objective is to extract meaningful business
insights and identify sales trends.

====================================================
               SQL ANALYSIS QUERIES
====================================================

SALES OVERVIEW
--------------
1. Total Number of Sales
2. Total Quantity Sold
3. Total Customers
4. Total Products

REVENUE ANALYSIS
----------------
5. Calculate Sales Revenue
6. Calculate Discounted Revenue
7. Total Revenue

SALES PERFORMANCE ANALYSIS
--------------------------
8. Product-wise Sales
9. Category-wise Sales
10. Region-wise Sales
11. Customer-wise Sales
12. Top 5 Customers
13. Top 5 Products
14. Monthly Sales
15. Payment Method Analysis

PROFIT ANALYSIS
---------------
16. Profit per Product
17. Category-wise Profit
18. Highest-Selling Product
19. Total Sales
20. Total Profit
21. Average Order Value
